# Mail-Symbole

Lucide Static 1.58.0, ISC-Lizenz (siehe LICENSE), aus dem vorhandenen
lokalen Lucide-Katalog der Lauffreunde-Beitragsgestaltung.

| Motiv | Verwendung |
| --- | --- |
| file-text | Rechnungsueberschrift |
| list-checks | Leistungsuebersicht |
| landmark | Bankverbindung |
| map-pin | Adresse im Footer |
| mail | E-Mail im Footer |
| phone | Telefon im Footer |

SVG-Quellen und daraus erzeugte transparente PNG-Dateien (48 × 48,
#333333). PNGs werden als lokale CID-Anhaenge eingebettet, ohne externe
Bildabrufe oder Webfonts. Darstellung je nach Position mit 14 bis 24 Pixeln.
`branding.mail_icons_enabled: false` schaltet alle Symbole gemeinsam aus;
Text und Logo bleiben erhalten. Nur tatsaechlich referenzierte Symbole werden
angehaengt. Keine neuen Laufzeitabhaengigkeiten.
